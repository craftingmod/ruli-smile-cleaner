# 황달 클리너

![아이콘](./assets/icons/smile.png)

루리웹에서 작성한 게시글과 댓글을 수집해 CSV로 백업한 뒤 삭제하는 클리너입니다.

[딸깍으로 배포된 황달 클리너](https://bbs.ruliweb.com/community/board/300143/read/66538672)를 실행하던 보안 취약점이 막혀, 사용자가 직접 실행하는 방식으로 다시 묶은 버전입니다. 다운로드 크기는 커졌지만 실제 삭제 스크립트는 같은 계열의 동작을 합니다.

## 실행법

[Releases](../../releases)에서 최신 버전을 다운로드합니다.

- **Portable**: 압축을 풀고 `황달클리너_실행.bat`을 실행합니다. 설치 없이 쓰려면 이쪽을 권장합니다.
- **Setup**: `Setup.exe`를 실행해 설치합니다.

앱 창이 뜨면 루리웹에 로그인합니다. 마이페이지로 이동한 뒤 실행 확인창이 뜨면 안내에 따라 진행합니다.

삭제 전에 게시글/댓글 목록을 CSV 파일로 백업하고, 삭제할 게시글 수와 댓글 수를 보여줍니다. 실제 삭제를 진행하려면 입력창에 `동의합니다`를 입력해야 합니다.

## 개발자 콘솔로 실행

앱을 다운로드하지 않고 브라우저 개발자 콘솔에서 직접 실행할 수도 있습니다.

브라우저가 콘솔 붙여넣기를 경고할 수 있습니다. 반드시 이 저장소의 [src/cleaner_dom.js](./src/cleaner_dom.js) 내용을 직접 확인한 뒤 실행해주세요.

1. 브라우저에서 루리웹에 로그인합니다.
2. `https://bbs.ruliweb.com/member/mypage/myarticle` 페이지로 이동합니다.
3. 개발자 도구를 열고 Console 탭으로 이동합니다.
4. [src/cleaner_dom.js](./src/cleaner_dom.js) 파일 내용을 전체 복사해 콘솔에 붙여넣고 실행합니다.
5. 게시글/댓글 수집 및 CSV 백업이 끝난 뒤 표시되는 개수를 확인합니다.
6. 정말 삭제하려면 입력창에 `동의합니다`를 입력합니다.

다른 사람이 전달한 축약/변조 스크립트는 사용하지 않는 것을 권장합니다.

## 주의사항

- 삭제된 게시글과 댓글은 복구할 수 없습니다.
- CSV 백업 파일이 정상적으로 저장됐는지 확인한 뒤 삭제를 진행하세요.
- 로그인 중 브라우저 권한 요청이 뜨면, 클리너 기능에는 보통 필요하지 않으므로 거절해도 됩니다. 간혹 CSV 다운로드가 안되었다면 클리너 작동 중에 묻는 권한만 허용해주세요.
- 사이트 구조나 API가 바뀌면 클리너가 동작하지 않을 수 있습니다.

## Q&A

**Q. 파일 구조도 실행 화면도 못생겼어요.**  
A. 원 구조를 최대한 유지하면서 가볍게 돌아가게 하려다 보니 그렇습니다.

**Q. 개인정보를 가져가나요?**  
A. 클리너 기능만 동작하며, 개인정보를 외부로 전송하지 않습니다. 걱정되면 콘솔 실행 방식으로 스크립트 내용을 확인하고 직접 실행할 수 있습니다.

**Q. 예전처럼 딸깍으로 실행할 수는 없나요?**  
A. 해당 방식은 보안 취약점에 의존하던 방식이라 현재는 불가능합니다.

## 개발자용

Electrobun으로 만든 앱이며, 루리웹 페이지에 [src/cleaner_dom.js](./src/cleaner_dom.js)를 preload로 주입합니다.

### Dev

```sh
bun install
bun start
```

### Build

```sh
bun run build:stable
```

Windows 배포물은 GitHub Actions에서 Setup zip과 Portable zip으로 생성됩니다.
